# LoZio mini app

Mini app Telegram per le partite tattiche di LoZio a Padel Village (giocatori e maestro).
Per ora contiene il prototipo navigabile; la versione collegata al bot arriva dopo.

Pubblicata con GitHub Pages dal ramo `main` (workflow `deploy-pages.yml`).
La vecchia versione (emulatore chat giocatori) è nella cronologia di git.
